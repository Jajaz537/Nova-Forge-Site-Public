Contrat MODARYX

PC disponible ne signifie pas fichier MODARYX disponible.

La présence officielle d’une version PC établit une plateforme. Elle n’accorde pas automatiquement à MODARYX les droits de redistribuer un mod tiers, ni la preuve qu’un mod fonctionne sur une version donnée.

Sources officielles consultées le 20 septembre 2026 : Rockstar Games — RDR2 disponible sur PC · Rockstar Support — configuration PC. MODARYX n’est pas affilié à Rockstar Games.
