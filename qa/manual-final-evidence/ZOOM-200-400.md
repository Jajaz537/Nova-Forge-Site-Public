# Preuve manuelle — Zoom navigateur natif 200 % / 400 %

**Preview :** https://6f813d33.nova-forge-site-public.pages.dev  
**État avant test :** PREUVE MANQUANTE  
**But :** vérifier le vrai zoom du navigateur, pas seulement le reflow simulé.

## Navigateur

Utiliser Chrome ou Edge natif sur Windows. Mettre la fenêtre en taille normale, idéalement maximisée. Ne pas utiliser les outils développeur pour simuler le zoom.

## Procédure

Pour **chacune des 23 routes** ci-dessous :

1. Ouvrir la route à **100 %** et attendre le chargement complet.
2. Passer à **200 %** avec `Ctrl` + `+` ou le menu du navigateur.
3. Parcourir la page du haut jusqu'au footer.
4. Vérifier le menu principal, les boutons, liens, formulaires et contrôles visibles.
5. Faire une capture plein écran ou une capture de page montrant clairement le niveau **200 %** si le navigateur l'affiche.
6. Passer à **400 %**.
7. Refaire le parcours du haut jusqu'au footer.
8. Tester le menu mobile/compact s'il apparaît.
9. Capturer toute anomalie séparément.
10. Revenir à 100 % avant de passer à la route suivante si nécessaire.

## Résultat attendu

À 200 % et 400 % :

- aucun texte essentiel tronqué ou superposé ;
- aucune perte d'information ;
- aucun contrôle indispensable hors écran sans moyen normal de l'atteindre ;
- pas de défilement horizontal de toute la page, sauf composant explicitement conçu pour défiler horizontalement ;
- navigation toujours utilisable ;
- focus clavier visible ;
- boutons et champs lisibles et actionnables ;
- contenu principal et footer accessibles ;
- images non cassées ;
- hero, cartes et panneaux ne doivent pas masquer le texte ;
- la page doit rester compréhensible sans dézoomer.

## Échec à signaler

Signaler immédiatement :

- texte coupé, chevauchement empêchant la lecture ;
- bouton inaccessible ;
- menu impossible à ouvrir/fermer ;
- champ de formulaire inutilisable ;
- scroll horizontal global important ;
- contenu qui disparaît ;
- zoom 400 % provoquant une page blanche ou une erreur ;
- focus invisible sur un contrôle utilisé au clavier.
