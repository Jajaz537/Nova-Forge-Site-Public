# MODARYX — quality gate du monde vivant

État : **EN COURS — direction canonique affinée ; les illustrations actuelles doivent encore être revérifiées/corrigées contre cette version**.

## Principe général

Le « sanctuaire » n'est pas une petite zone séparée : **c'est la philosophie du monde entier de MODARYX**.

Toute illustration majeure doit montrer un univers :

- vivant ;
- habitable ;
- naturel ;
- noble ;
- majestueux ;
- protecteur ;
- riche en biodiversité ;
- magique mais cohérent dans son imaginaire ;
- relié par la nature, l'eau, les chemins et l'architecture.

Une image techniquement correcte mais dominée par une roche stérile, une surcharge d'effets ou une composition artificielle reste **EN COURS**.

## Monde recherché

Le monde doit suggérer une vraie vie quotidienne et une vraie profondeur :

- forêts, arbres, mousses, fleurs, herbes et jardins ;
- vallées, montagnes, falaises et reliefs ancrés dans le terrain ;
- rivières, lacs, ruisseaux et quelques cascades naturelles bien placées ;
- chemins, ponts, terrasses, remparts, villages et architecture intégrée ;
- animaux réels et créatures appartenant naturellement à leur habitat ;
- quelques villageois, voyageurs ou habitants ;
- quelques soldats/gardes/protecteurs, avec mesure et sans ambiance de guerre permanente ;
- notre héros peut apparaître ponctuellement auprès des animaux, mais ne doit pas devenir le centre obligatoire de chaque illustration.

Le monde doit paraître **vécu**, pas seulement contemplé.

## Château / cité

Le château ou la cité principale doit :

- être immédiatement lisible ;
- en imposer ;
- être majestueux et mémorable ;
- structurer le panorama ;
- rester intégré au paysage ;
- être relié visuellement aux vallées, chemins, ponts, jardins et zones habitées.

Il ne doit pas être noyé dans le décor ni coupé par le cadrage.

## Ciel

**Interdiction artistique permanente : pas d'îles flottantes, pas de structures flottantes et pas d'objets artificiellement suspendus dans le ciel.**

Le ciel peut être spectaculaire par :

- la lumière ;
- les nuages ;
- la profondeur atmosphérique ;
- les montagnes et tours ancrées au sol ;
- les perspectives lointaines.

Le fantastique doit rester crédible dans les règles internes du monde.

## Eau

L'eau reste une composante importante, mais doit être dosée.

À privilégier :

- rivières ;
- lacs ;
- ruisseaux ;
- quelques grandes cascades naturelles ;
- bassins et sources lorsque justifiés ;
- quelques fontaines nobles seulement si elles ont un rôle architectural clair.

À éviter :

- multiplication de fontaines ;
- jets d'eau partout ;
- cascades répétées comme effet décoratif automatique ;
- surenchère aquatique destinée uniquement à « faire fantasy ».

## Animaux et créatures

Les animaux ne doivent jamais sembler simplement « posés sur une pierre ».

Vérifier :

- appuis cohérents ;
- habitat cohérent ;
- échelle ;
- intégration dans la végétation et le terrain ;
- relation avec l'eau, les chemins et les zones de vie ;
- variété des espèces lorsque la scène le permet.

Le loup et le dragon restent des repères visuels importants, mais le monde doit exister pleinement autour d'eux.

## Héros

Notre héros :

- peut apparaître de temps en temps ;
- peut accompagner les animaux ;
- doit servir la narration ;
- ne doit pas être présent partout ;
- ne doit pas écraser le paysage, la cité ou la faune.

## Composition

Chaque illustration majeure doit vérifier :

- visibilité du château/cité si présent ;
- point focal clair ;
- profondeur ;
- plans lisibles ;
- ciel non encombré ;
- eau bien dosée ;
- animaux intégrés ;
- signes de vie humaine mesurés ;
- équilibre nature / architecture ;
- absence de roche grise dominante sans raison narrative ;
- absence de surcharge de détails tous au même niveau.

## Responsive et cadrage

Une illustration n'est pas validée uniquement parce qu'elle ne déborde pas.

Vérifier réellement sur les viewports pertinents :

- sujet principal non coupé ;
- château visible ;
- animaux non tronqués ;
- point focal préservé ;
- profondeur maintenue ;
- composition lisible sur mobile, tablette, desktop et grand écran.

Adapter si nécessaire `object-position`, hauteur, ratio ou asset/cadrage spécifique au viewport.

## Corrections déjà intégrées au lot précédent

- `modaryx-wolf-dragon-hero.webp` : habitat plus végétalisé, créatures mieux intégrées et cité davantage reliée au paysage.
- `modaryx-world-portals.webp` : monde continu davantage habité et naturel.

Ces deux fichiers **ne sont plus considérés définitivement validés** tant qu'ils n'ont pas été confrontés aux nouvelles règles explicites ci-dessus, notamment :

- absence d'îles/objets flottants ;
- réduction des fontaines/cascades excessives ;
- château réellement imposant ;
- présence crédible d'animaux réels et de vie humaine mesurée ;
- héros seulement lorsque pertinent.

## Gate permanent

Pour toute future illustration majeure, vérifier explicitement :

1. monde vivant et habitable ;
2. biodiversité ;
3. intégration des créatures ;
4. château/cité lisible lorsque présent ;
5. ciel sans îles/objets flottants ;
6. eau dosée ;
7. variété des biomes ;
8. chaleur et signes de vie ;
9. profondeur ;
10. cadrage responsive ;
11. absence de décor minéral générique ;
12. absence de surcharge décorative.

Une image techniquement valide mais artistiquement insuffisante reste **EN COURS**.
