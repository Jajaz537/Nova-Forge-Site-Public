# MODARYX V2 — surfaces légales publiques / readiness France-UE — candidat — 2026-10-08

**État : EN COURS / BLOQUÉ selon les modules — aucun texte légal final publiable**

Ce registre prépare les surfaces publiques minimales avant lancement. Il ne remplace pas une validation juridique adaptée au modèle commercial, à l'entité opératrice et aux territoires effectivement ciblés.

## 1. Mentions légales

Les sources officielles françaises indiquent qu'un site professionnel doit permettre d'identifier son éditeur/responsable et son hébergeur, avec des informations qui dépendent notamment de la forme juridique et de l'activité.

À préparer lorsque les faits existent :
- identité/dénomination et forme juridique ;
- adresse et contacts ;
- immatriculation/RNE/RCS selon le cas ;
- TVA intracommunautaire si applicable ;
- directeur/responsable de publication selon le cas ;
- hébergeur et coordonnées requises ;
- crédits/propriété intellectuelle lorsque nécessaire.

**BLOQUÉ** aujourd'hui sur l'identité opérateur, la forme juridique, les identifiants, la TVA et plusieurs faits de production.

## 2. CGU / règles d'utilisation

Candidat à rédiger autour de :
- compte et sécurité ;
- usage acceptable ;
- UGC, contenus, mods et droits ;
- règles créateurs ;
- signalement/modération/appels ;
- anti-abus/fraude ;
- fermeture/suspension de compte ;
- propriété intellectuelle ;
- évolution du service ;
- support/contact.

Ne pas verrouiller juridiction, droit applicable, limitations ou clauses consommateurs sans revue juridique.

État : **EN COURS**.

## 3. CGV / vente aux consommateurs

**BLOQUÉ** tant qu'il n'existe pas de :
- vendeur/opérateur final ;
- offre payante canonique ;
- prix canonique ;
- provider paiement ;
- modèle fiscal/facturation ;
- qualification finale du produit numérique/service.

Le futur parcours de commande devra notamment présenter clairement les caractéristiques essentielles, le prix total, la durée/renouvellement/résiliation, les modalités de paiement et les informations propres aux contenus/services numériques lorsque applicables.

Aucun bouton d'achat ni prix n'est activé par ce document.

## 4. Rétractation / remboursement

Cadre candidat France/UE :
- les contrats consommateurs conclus à distance sont en principe associés à un droit de rétractation de 14 jours, sous réserves/exceptions prévues par les textes ;
- le professionnel doit informer clairement de l'existence, de l'absence ou de la perte éventuelle de ce droit et de ses modalités ;
- le remboursement applicable est encadré par des délais/moyens de paiement ;
- **services numériques** et **contenus numériques fournis en ligne** ne doivent pas être confondus.

Point critique :
la perte du droit de rétractation pour certains contenus numériques ne doit jamais être codée comme règle automatique « accès commencé = droit perdu ». Les conditions de consentement/acknowledgement requises doivent être prouvées pour le cas réel.

À préparer :
- formulaire/process de rétractation si requis ;
- reçu durable ;
- workflow refund ;
- effet sur accès/compte ;
- restitution de contenus créés par l'utilisateur lorsque applicable.

État : **PREUVE MANQUANTE / LEGAL_REVIEW_REQUIRED**.

## 5. Accessibilité du commerce électronique

Les sources françaises/UE indiquent que les exigences issues de l'European Accessibility Act s'appliquent depuis le **28 juin 2025** à certaines catégories, dont le commerce électronique lorsque le service entre dans le champ applicable.

Le projet doit donc continuer à construire :
- clavier ;
- lecteurs d'écran ;
- contraste ;
- zoom/reflow ;
- reduced motion ;
- formulaires/erreurs ;
- authentification ;
- consentement ;
- paiement/checkout si activé ;
- support ;
- pages légales/privacy.

Une éventuelle exemption liée à la taille de l'entreprise ou une charge disproportionnée **ne doit pas être supposée** : elle dépend de faits réels et d'une qualification juridique.

État :
- accessibilité produit : **EN COURS**
- tests réels assistive tech : **PREUVE MANQUANTE**
- applicabilité réglementaire finale : **PREUVE MANQUANTE**
- éventuelle exemption : **PREUVE MANQUANTE**
- surface publique de conformité/déclaration : **PREUVE MANQUANTE**
