# MODARYX V2 — Script de validation humaine low‑fi

**Date : 2026-10-03**
**Statut : PREUVE MANQUANTE — protocole prêt**

## 1. But

Valider que la structure et les libellés permettent aux utilisateurs de réaliser les tâches essentielles avant toute direction artistique.

## 2. Participants

Cible idéale :
- joueurs habitués aux mods ;
- joueurs peu expérimentés ;
- au moins un créateur de contenu/mod si possible.

Ne pas utiliser uniquement des personnes déjà familières avec MODARYX.

## 3. Consigne

Montrer les wireframes low‑fi sans expliquer la navigation.

Demander aux participants de dire où ils cliqueraient et pourquoi.

Ne pas aider avant qu'ils aient exprimé leur premier choix.

## 4. Tâches

### T1 — Trouver un plugin

“Tu veux ajouter un plugin à un jeu précis. Où vas-tu ?”

Succès attendu :
Jeux → Hub jeu → Mods & Plugins / recherche.

### T2 — Vérifier une version

“Tu as trouvé un mod. Comment vérifies-tu qu'il fonctionne avec ta version du jeu ?”

Succès attendu :
Fiche → compatibilité / requirements.

### T3 — Dépendances

“Avant installation, tu veux savoir s'il manque quelque chose.”

Succès attendu :
Fiche → requirements / dépendances.

### T4 — Conflits

“Tu veux vérifier si ce mod entre en conflit avec quelque chose.”

Succès attendu :
Fiche → requirements / conflits.

### T5 — Historique

“Tu veux revenir à une ancienne version.”

Succès attendu :
Fiche → versions/files.

### T6 — Collection

“Tu veux garder ce mod dans une liste pour plus tard.”

Succès attendu :
Fiche/quick view → ajouter à collection.

### T7 — Profil

“Tu veux sauvegarder une configuration de mods précise.”

Succès attendu :
Bibliothèque → Profils / Loadouts.

### T8 — Publier

“Tu es créateur et tu veux publier une nouvelle version.”

Succès attendu :
Créer → Creator Studio → Project → Releases.

### T9 — Créateur

“Tu connais le nom d'un créateur et veux retrouver ses projets.”

Succès attendu :
Recherche globale ou Créateurs → profil.

### T10 — Signaler

“Tu as un problème avec un contenu.”

Succès attendu :
Fiche → support/signalement.

## 5. Mesures

Pour chaque tâche :

- premier choix ;
- chemin suivi ;
- succès/échec ;
- hésitations ;
- retours arrière ;
- mots incompris ;
- temps approximatif ;
- commentaire spontané.

## 6. Seuil de correction

Une tâche critique doit être corrigée avant high‑fi si :

- plusieurs participants choisissent le mauvais premier niveau ;
- le même libellé est compris différemment ;
- une dépendance/compatibilité est recherchée dans une zone inattendue ;
- le participant doit deviner un terme de lore ;
- le mobile nécessite plus d'étapes sans raison.

## 7. Questions de fin

- “En une phrase, à quoi sert MODARYX ?”
- “Où chercherais-tu d'abord un mod pour ton jeu ?”
- “Quelle différence comprends-tu entre collection et profil ?”
- “Où vérifies-tu si quelque chose est compatible ?”
- “Qu'est-ce qui te mettrait en confiance avant d'installer ?”
- “Quel élément t'a paru inutile ou confus ?”

## 8. Gate

Le test ne valide pas l'esthétique.

Il valide uniquement :
- trouvabilité ;
- compréhension ;
- hiérarchie fonctionnelle ;
- terminologie.
