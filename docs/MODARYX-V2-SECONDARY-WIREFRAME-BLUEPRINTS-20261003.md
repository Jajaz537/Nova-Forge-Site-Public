# MODARYX V2 — Blueprints wireframes secondaires

**Date : 2026-10-03**
**Statut : conception textuelle — écriture Figma bloquée par quota Starter**

## 1. Mobile Collection

Priorités :

1. nom + curateur ;
2. jeu/version ;
3. statut compatibilité ;
4. nombre d'items ;
5. dépendances/conflits ;
6. action principale ;
7. liste des items ;
8. notes du curateur.

États :
- collection vide ;
- item retiré ;
- item incompatible ;
- dépendance manquante ;
- offline/stale.

## 2. Mobile Modpack

Priorités :

1. nom + version ;
2. jeu + version jeu ;
3. loader ;
4. statut installable ;
5. dépendances ;
6. conflits ;
7. changelog ;
8. action manager/manual si disponible.

Pas d'installation simulée.

## 3. Mobile Profile / Loadout

Priorités :

1. jeu + instance ;
2. état local/sync ;
3. releases sélectionnées ;
4. conflits ;
5. load order ;
6. updates ;
7. actions de sauvegarde/export.

États :
- local-only ;
- sync-pending ;
- conflict ;
- manager unavailable.

- projets ;
- releases ;

Upload lourd :
- disponible uniquement si fiable ;
