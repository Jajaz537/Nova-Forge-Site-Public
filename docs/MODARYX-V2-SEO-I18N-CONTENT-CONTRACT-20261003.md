# MODARYX V2 — Contrat SEO, internationalisation et contenu

**Date : 2026-10-03**
**Statut : conception — aucun frontend V2 implémenté**

## SEO

Chaque surface indexable doit avoir :
- title unique ;
- description utile ;
- canonical cohérent ;
- données structurées seulement si exactes ;
- sitemap ;
- URLs lisibles ;
- gestion explicite des pages retirées.

Les filtres ne doivent pas générer un nombre incontrôlé d'URLs indexables.

## Internationalisation

Prévoir dès la conception :
- textes plus longs ;
- pluriels ;
- formats de date/nombre ;
- langues multiples ;
- contenus créateurs non traduits ;
- recherche accent-insensitive.

Ne pas figer les layouts sur la longueur du français.

## Contenu

Distinguer :
- interface MODARYX ;
- métadonnées créateur ;
- descriptions ;
- guides ;
- contenu communautaire.

Les messages système doivent rester fonctionnels et non ambigus.

## États éditoriaux

Prévoir :
- draft ;
- published ;
- updated ;
- archived ;
- removed.

Un contenu retiré garde un comportement URL/documenté cohérent.

## Pages jeu

Un Game Hub ne doit être indexé comme catalogue actif que si son statut le justifie.

Un hub éditorial seul ne doit pas laisser croire que des mods sont distribués.

## Fiches contenu

Metadata minimale :
- titre ;
- jeu ;
- type ;
- auteur ;
- release ;
- état.

Ne pas exposer de faux chiffres ou de compatibilité non prouvée dans les snippets.

## Accessibilité éditoriale

- titres hiérarchiques ;
- liens descriptifs ;
- textes alternatifs utiles ;
- langage clair pour erreurs et statuts.

## Gate

Avant implémentation :
- stratégie URLs ;
- canonical ;
- indexation filtres ;
- i18n-ready ;
- états éditoriaux ;
- contenu supprimé/archivé.
