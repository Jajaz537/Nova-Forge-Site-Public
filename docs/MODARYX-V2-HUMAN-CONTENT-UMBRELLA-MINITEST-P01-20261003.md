# MODARYX V2 — Mini-test humain du libellé parapluie — P01

**Date : 2026-10-03**  
**Statut : TERMINÉ pour P01 — validation humaine globale EN COURS**

## 1. Contexte

Après benchmark externe multi-gaming / gaming / modding, trois candidats ont été présentés à P01 sans révéler le candidat éventuellement favorisé par l'analyse :

- A. **Contenus de jeu**
- B. **Mods & contenus**
- C. **Créations**
- D. autre proposition

Scénario :
chercher sur MODARYX aussi bien un mod, un plugin, une map, un shader, un script ou un outil.

## 2. Réponse brute P01

**B — Mods & contenus**

## 3. Lecture

Pour P01 :
- le mot **Mods** garde un ancrage immédiatement reconnaissable dans le modding ;
- le mot **contenus** ouvre naturellement au-delà des seuls mods/plugins ;
- ce choix est plus large que **Mods & Plugins** ;
- il évite la collision potentielle de **Créations** avec Créateurs / Créer / Creator Studio ;
- il semble plus explicite que **Contenus de jeu** pour une plateforme centrée sur le modding.

## 4. Décision de travail

**Libellé parapluie UI provisoire préféré : Mods & contenus**

Ce choix :
- remplace **Mods & Plugins** comme candidat primaire ;
- ne change pas les types métier sous-jacents ;
- reste à consolider avec d'autres humains avant gel high-fi final.

La taxonomie détaillée reste :
mods, plugins, addons, scripts, maps, shaders, presets, outils et autres types applicables au jeu.

## 5. Limite de preuve

P01 reste un seul participant réel.

Aucune statistique générale n'est déduite de cette préférence.

**État : préférence humaine réelle obtenue pour P01 / validation globale EN COURS.**
