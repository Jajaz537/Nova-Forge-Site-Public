# MODARYX V2 — DESIGN CANONIQUE HUMAIN — 2026-10-05

**Statut : VERROUILLÉ PAR DÉCISION HUMAINE**
**Périmètre : plateforme web MODARYX**
**Référence : capture utilisateur du Game Hub « Aurelian Vale » transmise le 5 octobre 2026.**

## Décision

La cible visuelle officielle du site MODARYX n'est plus le hero narratif « voyageur + loup + bébé dragon » ni les variantes dérivées de ce hero.

La référence humaine courante est le **Game Hub produit** montré dans la capture Aurelian Vale.

Les anciennes directions hero/cinématiques restent uniquement de la provenance historique. Elles ne doivent plus être utilisées pour guider la VF web actuelle.

## Structure visuelle verrouillée

La famille visuelle doit conserver :

- topbar MODARYX sombre ;
- navigation principale : Découvrir, Jeux, Mods & contenus, Collections, Créateurs, Communauté ;
- recherche et compte à droite ;
- bouton Démonstration ;
- grand bandeau **contextuel au jeu**, pas un hero marketing générique ;
- vignette du jeu à gauche ;
- nom du jeu + version ;
- recherche « Rechercher dans ce jeu » ;
- CTA « Explorer les contenus » ;
- navigation locale sous le bandeau ;
- zone principale « Pour votre version » ;
- filtres compacts ;
- contenus présentés prioritairement en lignes produit denses sur desktop ;
- rail droit « Mes profils pour ce jeu » ;
- responsive mobile dérivé de la même structure, sans perdre la hiérarchie produit.

## Palette verrouillée

**Mélange équilibré bleu nuit + violet premium.**

Règles :

- fonds : bleu nuit / quasi-noir ;
- surfaces : bleu très sombre neutre ;
- accents actifs : cyan/bleu clair contrôlé ;
- profondeur premium : violet ;
- CTA : bleu → violet ou cyan/bleu selon fonction, sans transformer tout le site en bleu ;
- profils : violet plus présent ;
- pas de néon agressif ;
- pas de site « tout bleu » ;
- pas de site « tout violet ».

## Typographie et densité

- sans-serif produit ;
- hiérarchie compacte ;
- densité desktop proche d'une bibliothèque/mod manager premium ;
- cartes éditoriales plein écran non prioritaires dans le Game Hub ;
- bordures, séparateurs et surfaces sobres.

## Statut des anciennes directions

Les variantes suivantes sont **REJETÉES COMME CIBLES VF WEB** :

- hero plein écran narratif ;
- composition voyageur/loup/dragon comme page d'accueil directrice ;
- variantes marketing cinématiques ;
- interprétations visuelles qui changent la structure du Game Hub de référence.

Elles peuvent rester dans Git pour provenance/compatibilité tant qu'elles sont explicitement classifiées et qu'aucun mécanisme ne les remet comme cible courante.

## Discipline

Toute modification visuelle future doit être comparée à ce canon avant promotion.

Un test automatique ne remplace pas la validation humaine, mais doit empêcher une régression structurelle évidente vers les anciennes directions.

**Décision humaine fraîche du 2026-10-05 : ce document supersède les anciennes décisions artistiques web lorsqu'elles divergent.**
