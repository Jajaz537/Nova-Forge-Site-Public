# MODARYX V2 — PRICING RESEARCH INSTRUMENT — 2026-10-07

**Statut : PRÊT POUR RECHERCHE / AUCUNE VENTE / AUCUN PRIX CANONIQUE**

Ce questionnaire opérationnalise le protocole `MODARYX-V2-PRICING-VALIDATION-PROTOCOL-20261007.md`.
Il ne collecte aucune carte, ne crée aucune commande et ne présente aucun prix comme décidé.

## 1. Recrutement / qualification

Questions minimales :
1. Utilisez-vous des mods aujourd'hui ? Jamais / occasionnellement / mensuellement / hebdomadairement.
2. Sur combien de jeux moddez-vous actuellement ? 0 / 1 / 2–3 / 4+.
3. Quels types d'outils utilisez-vous ? plateformes de mods / gestionnaire / outils manuels / créations propres / autre.
4. Vous considérez-vous surtout : découverte / joueur avancé / créateur / mainteneur d'une collection-modpack.
5. Plateforme principale : Windows / Linux / macOS / Steam Deck / autre.
6. Acceptez-vous de répondre à une recherche produit MODARYX sans achat réel ? oui/non.

Ne pas demander identité réelle si elle n'est pas nécessaire à l'étude.

## 2. Valeur du cœur gratuit

Présenter le cœur gratuit sans le dégrader :
- recherche/découverte ;
- compatibilité, dépendances et conflits ;
- provenance/licence/sécurité ;
- favoris/collections ;
- publication créateur de base ;
- communauté/signalement ;
- téléchargement manuel lorsqu'autorisé.

Échelles 1–5 :
- « Cette offre serait utile même si je ne paie jamais. »
- « Je ferais confiance à une plateforme qui affiche clairement compatibilité et provenance. »
- « Je l'essaierais sur un de mes jeux. »

Question ouverte :
- « Qu'est-ce qui manquerait au gratuit pour que vous le considériez comme un vrai bon produit ? »

Un faible score du gratuit est un problème produit, pas une justification pour déplacer artificiellement une fonction vers Premium.

## 3. Valeur Premium à tester séparément

Faire noter indépendamment :
- profils/loadouts avancés ;
- verrouillage de versions + rollback ;
- installation automatisée lorsqu'autorisée ;
- résolution avancée de conflits ;
- synchronisation cloud seulement si réellement prévue ;
- confort/personnalisation avancée.

Pour chaque fonction :
- importance 1–5 ;
- fréquence d'usage anticipée ;
- « indispensable gratuit / premium acceptable / sans intérêt ».

Ne jamais proposer sécurité de base, accessibilité, consentement privacy ou fonctions essentielles de récupération comme upsell.

## 4. Test de modèle économique

Avant tout prix :
- préférence : gratuit uniquement / achat ponctuel / abonnement mensuel / abonnement annuel / indifférent ;
- « Qu'est-ce qui rendrait un abonnement légitime chaque mois ? »
- « Qu'est-ce qui vous ferait refuser un abonnement même si le produit vous plaît ? »

Mesurer séparément le rejet de l'abonnement.

## 5. Test prix — méthode recommandée

Stimuli de recherche :
- 4,99 €/mois
- 6,99 €/mois
- 8,99 €/mois

Pour limiter l'ancrage, utiliser d'abord une **présentation monadique randomisée** : chaque répondant voit un seul prix.

Question :
« Si les fonctions Premium que vous jugez utiles étaient réellement disponibles et si le gratuit restait complet, quelle serait votre réaction à [PRIX] ? »
- je paierais probablement ;
- j'envisagerais après essai ;
- trop cher ;
- je refuse surtout l'abonnement ;
- pas assez de valeur Premium.

Ensuite seulement, demander une préférence entre mensuel/annuel/achat ponctuel.

Ne jamais présenter la réponse comme une réservation ou une commande.

## 6. Van Westendorp facultatif

Sans remplacer la mesure comportementale :
- à quel prix Premium semblerait trop bon marché pour inspirer confiance ?
- à quel prix semblerait raisonnable ?
- à quel prix commencerait à sembler cher ?
- à quel prix serait trop cher pour être envisagé ?

Analyser par segment ; ne pas transformer l'intersection en prix automatique.

## 7. Créateurs — étude séparée

Ne pas mélanger avec Premium joueur.

Tester :
- équipes ;
- analytics avancées ;
- automatisation/API ;
- support pro ;
- gestion de releases et droits.

Questions :
- gain de temps attendu ;
- problème actuel ;
- besoin équipe/pro ;
- paiement préféré ;
- refus de commission.

Aucune commission n'est introduite par cette étude.

## 8. Guide entretien qualitatif — 30 à 45 min

1. Racontez la dernière fois qu'un mod vous a posé un vrai problème.
2. Comment l'avez-vous résolu ?
3. Qu'est-ce qui vous fait confiance ou fuir une plateforme de mods ?
4. Montrez-moi ce qui serait indispensable dans un gratuit honnête.
5. Parmi les fonctions avancées, laquelle résout un problème assez fort pour payer ?
6. Qu'attendriez-vous d'un abonnement au bout de 3 mois ?
7. Que préféreriez-vous acheter une seule fois ?
8. Quelle donnée refuseriez-vous que MODARYX collecte ?
9. Comment voudriez-vous être informé d'un conflit/licence/risque ?
10. Qu'est-ce qui vous ferait recommander MODARYX ?

Ne pas vendre pendant l'entretien.

## 9. Échantillon candidat

Qualitatif :
- 12–20 personnes ;
- couvrir découverte, avancé, créateur ;
- éviter un échantillon composé uniquement de power users.

Quantitatif :
- 150–300 réponses qualifiées ;
- analyser au minimum par segment et fréquence de modding.

Ce sont des objectifs de recherche, pas des seuils statistiques garantis.

## 10. Données à enregistrer

Agrégats recommandés :
- segment ;
- fréquence de modding ;
- fonctions jugées indispensables gratuites ;
- top 3 valeur Premium ;
- intention par prix randomisé ;
- refus abonnement ;
- préférence achat ponctuel/annuel ;
- confiance privacy ;
- objections.

Éviter de collecter date de naissance exacte, adresse, données sensibles ou identifiants inutiles.

## 11. Critères de décision

Aucun prix canonique avant :
- gratuit jugé réellement utile ;
- fonction Premium récurrente clairement comprise ;
- résultats par segment ;
- pilote d'usage réel ;
- activation/rétention ;
- coûts réels ;
- refunds/chargebacks projetés puis mesurés ;
- TVA/paiement/legal readiness ;
- décision explicite propriétaire.
