# MODARYX V2 — Politique d’ambiance par jeu et garde-fous de propriété intellectuelle

**Date : 2026-10-04**  
**Statut : ACTIF — politique produit / juridique préventive / ne remplace pas un avis juridique externe**

## 1. Décision produit

MODARYX peut adapter l’ambiance visuelle de chaque Game Hub au jeu sélectionné.

Exemples :
- GTA VI → ambiance urbaine/tropicale/électrique **originale MODARYX** ;
- Red Dead Redemption 2 → ambiance naturelle/cinématique/poussière/lumière chaude **originale MODARYX** ;
- Minecraft → ambiance modulaire/voxel **sans reprendre les textures, UI ou assets Mojang/Microsoft** ;
- Cyberpunk 2077 → ambiance technologique contrastée **sans reproduire l’UI, la typographie ou les codes de marque propriétaires à l’identique**.

La règle centrale est :

> **On change de monde, pas de produit.**

MODARYX reste visuellement dominant et reconnaissable sur toutes les pages de jeu.

## 2. Principe légal/prudentiel

La plateforme peut utiliser le **nom du jeu** pour identifier la compatibilité ou la destination du contenu lorsque cet usage est descriptif/référentiel et conforme aux usages honnêtes.

En revanche, l’utilisation d’éléments protégés ne doit jamais être présumée autorisée simplement parce que le jeu est cité.

Par défaut, sont **interdits sans licence, permission explicite ou base juridique clairement documentée** :
- logos officiels ;
- key arts ;
- affiches promotionnelles ;
- screenshots officiels/promos ;
- personnages ou portraits officiels ;
- musiques ;
- sons ;
- textures ;
- icônes ;
- polices spécifiques ;
- cartes officielles ;
- UI copiée ou imitation trop proche ;
- compositions graphiques susceptibles de créer une confusion d’affiliation.

La politique Rockstar consultée le 4 octobre 2026 indique notamment que sa tolérance pour certains contenus fan concerne des usages non commerciaux et n’autorise pas automatiquement l’exploitation de ces éléments pour promouvoir un produit ou service.

## 3. Règle de conception

Chaque Game Hub peut définir une **Game Atmosphere Layer** composée exclusivement de matériaux originaux MODARYX :

- palette ;
- gradient ;
- lumière ;
- profondeur ;
- densité ;
- grain ;
- texture générique ;
- animation ;
- motion ;
- silhouettes abstraites ;
- environnement générique ;
- weather layer ;
- seasonal layer ;
- ambient particles ;
- sound design uniquement si original/licencié.

Le squelette produit reste stable :
- navigation ;
- cartes ;
- typographie MODARYX ;
- composants ;
- espacement ;
- interactions ;
- accessibilité ;
- états ;
- hiérarchie ;
- boutons ;
- filtres ;
- provenance ;
- compatibilité.

## 4. Identité MODARYX dominante

Toujours :
- logo MODARYX ;
- navigation MODARYX ;
- design system MODARYX ;
- composants MODARYX ;
- typographie MODARYX ou licenciée pour MODARYX ;
- focus/accessibilité MODARYX ;
- wording MODARYX.

Jamais :
- reproduire l’interface officielle du jeu ;
- donner l’impression que MODARYX est le site officiel de l’éditeur ;
- placer le branding d’un jeu au-dessus de MODARYX au point de créer une confusion ;
- copier une campagne marketing ou un key art.

## 5. Utilisation des noms de jeux

Usage autorisé par défaut dans le produit :
- titre texte du jeu ;
- compatibilité ;
- filtres ;
- recherche ;
- fiches ;
- navigation ;
- métadonnées ;
- mentions de versions/éditions/plateformes.

Précautions :
- pas de stylisation imitant le logo officiel ;
- pas de claim d’affiliation ;
- pas de badge « officiel » sans contrat réel ;
- pas de wording laissant croire à un partenariat.

Lorsque pertinent :
> MODARYX est une plateforme indépendante et n’est pas affiliée à l’éditeur ou au détenteur de la marque, sauf indication explicite contraire.

## 6. Registre de droits par jeu

Avant toute utilisation d’un asset non créé par MODARYX, créer une entrée dans un futur **Game Rights Registry** avec :

- GameId ;
- nom du jeu ;
- éditeur ;
- propriétaire de la marque ;
- type d’asset ;
- source ;
- licence ;
- portée ;
- territoire si applicable ;
- usage autorisé ;
- date de vérification ;
- date d’expiration si applicable ;
- preuve ;
- reviewer ;
- statut : Allowed / Restricted / Forbidden / Unknown.

Règle :
- **Unknown = ne pas utiliser** ;
- **Forbidden = bloqué** ;
- **Restricted = uniquement dans la portée documentée** ;
- **Allowed = usage conforme à la preuve enregistrée**.

## 7. Catégories d’assets

### A. Original MODARYX
Autorisé si créé en interne ou pour MODARYX avec droits appropriés.

### B. User/creator supplied
Nécessite :
- déclaration de droits ;
- conditions d’upload ;
- mécanisme de signalement/takedown ;
- aucune validation automatique de propriété uniquement parce que le fichier a été uploadé.

### C. Publisher supplied / licensed
Autorisé uniquement selon la licence/permission enregistrée.

### D. Publicly available but not licensed
**Ne pas confondre “visible sur Internet” avec “libre d’utilisation”.**

## 8. Atmosphère inspirée vs copie

Acceptable :
- « mégalopole tropicale nocturne » ;
- « frontier western naturelle » ;
- « esthétique voxel abstraite » ;
- « science-fiction néon originale ».

À éviter :
- palettes trop précisément calquées sur une campagne officielle si elles deviennent identifiantes à elles seules ;
- mise en page identique ;
- écrans de chargement copiés ;
- motifs propriétaires ;
- typographie de logo ;
- silhouettes de personnages reconnaissables ;
- iconographie spécifique du jeu.

## 9. Images générées ou commandées pour MODARYX

Toute image produite pour une Game Atmosphere Layer doit être briefée comme :
- originale ;
- sans logos ;
- sans personnages propriétaires ;
- sans reproduction d’artwork officiel ;
- sans imitation d’interface officielle ;
- sans copie de key art ;
- sans texte de marque.

Les prompts/design briefs doivent décrire :
- ambiance ;
- époque ;
- environnement ;
- lumière ;
- matériaux ;
- motion ;
- composition ;
sans demander une reproduction exacte d’un asset protégé.

## 10. Screenshots et médias de mods

Les screenshots fournis par créateurs/utilisateurs restent un cas séparé de l’ambiance officielle MODARYX.

Le futur système devra :
- stocker provenance/owner declaration ;
- permettre signalement ;
- respecter takedown ;
- distinguer média du mod et média officiel du jeu ;
- ne pas réutiliser automatiquement un screenshot uploadé comme background marketing MODARYX.

## 11. Musique et audio

Par défaut :
- aucune musique officielle du jeu ;
- aucun OST ;
- aucun son repris du jeu ;
- aucun extrait promotionnel.

Utiliser seulement :
- audio original MODARYX ;
- bibliothèque avec licence commerciale claire ;
- contenu éditeur explicitement autorisé.

## 12. Game Atmosphere Engine

Concept retenu pour la VF :

`Game Atmosphere Engine`

Entrées conceptuelles :
- GameId ;
- palette sémantique ;
- environnement ;
- luminosité ;
- saison ;
- heure locale ;
- météo optionnelle ;
- motion profile ;
- texture profile ;
- intensity ;
- accessibility override ;
- rights profile.

Sortie :
- tokens visuels secondaires appliqués autour du design system MODARYX.

Le moteur ne doit jamais charger un asset externe propriétaire simplement parce qu’un GameId est sélectionné.

## 13. Accessibilité et contrôle utilisateur

Toujours prévoir :
- thème MODARYX uniforme ;
- réduire/désactiver l’ambiance par jeu ;
- reduced motion ;
- contraste minimum conservé ;
- aucune information transmise uniquement par décor ;
- désactivation weather/particles ;
- fallback performance.

L’ambiance ne doit jamais dégrader :
- lisibilité ;
- navigation ;
- performance ;
- accessibilité ;
- compréhension de compatibilité/provenance.

## 14. Garde-fous CI futurs

Avant production, ajouter des checks capables de détecter au minimum :
- domaines/URLs d’assets externes non allowlistés ;
- logos officiels blacklistés connus ;
- assets sans provenance ;
- dossiers marketing non classifiés ;
- licences manquantes ;
- références de marque dans des noms de fichiers UI non autorisés ;
- import direct depuis anciens assets historiques non classifiés.

## 15. Revue éditeur spécifique

Pour chaque éditeur important :
- vérifier politique de marque ;
- politique fan content ;
- politique de mods ;
- API/press kit ;
- conditions de commercialisation ;
- autorisations de screenshots/logos si nécessaire.

Exemple Rockstar/Take-Two :
- utiliser le nom du jeu de façon référentielle ;
- aucun asset officiel dans l’identité MODARYX sans permission/licence claire ;
- demander une licence si un usage marketing propriétaire devient nécessaire.

## 16. Takedown et escalade

Prévoir avant lancement public :
- contact IP/copyright ;
- workflow de takedown ;
- gel immédiat d’un asset contesté ;
- conservation des preuves/licences ;
- remplacement par fallback MODARYX original ;
- pas de réupload automatique.

## 17. Règle de VF

Avant VF, chaque Game Atmosphere Layer doit être classée :

- **Original MODARYX — TERMINÉ**
- **Licensed — preuve présente**
- **Restricted — périmètre documenté**
- **Unknown — BLOQUÉ**
- **Forbidden — exclu**

Aucune page de jeu ne doit dépendre d’un asset `Unknown` pour son rendu final.

## 18. Statut actuel

**TERMINÉ — politique de conception et garde-fous définis.**

Toujours à implémenter avant production :
- Game Rights Registry réel ;
- checks CI droits/assets ;
- politique de takedown opérationnelle ;
- revue éditeur par éditeur ;
- Game Atmosphere Engine réel ;
- validation juridique externe si usage commercial sensible ou asset officiel envisagé.

Cette politique réduit fortement le risque, mais ne garantit pas l’absence absolue de litige et ne remplace pas un avis juridique professionnel.
