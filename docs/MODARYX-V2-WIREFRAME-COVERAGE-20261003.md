# MODARYX V2 — Revue heuristique de couverture des wireframes

**Date : 2026-10-03**
**Statut : EN COURS — revue de conception, pas une validation humaine**

## 1. Objet

Comparer l'architecture produit décidée aux wireframes low-fi actuellement présents afin de détecter les écrans manquants avant toute direction artistique.

## 3. Écarts identifiés

### Game Hub — MANQUANT

Le hub jeu est pourtant un nœud central du flow :

Accueil / Jeux → **Hub jeu** → Catalogue contextualisé → Fiche.

Il doit permettre :
- identité du jeu ;
- recherche dans le jeu ;
- version active ;
- types de contenus disponibles ;
- catégories ;
- contenus populaires / récents / mis à jour ;
- collections ;
- créateurs ;
- guides utiles.

**Décision : ajouter un wireframe desktop Game Hub et une adaptation mobile.**

### Global Search — SOUS-REPRÉSENTÉ

La recherche est présente dans plusieurs écrans, mais la surface globale dédiée n'est pas encore matérialisée.

Elle doit agréger :
- jeux ;
- contenus ;
- créateurs ;
- collections.

**Décision : ajouter un wireframe Global Search desktop.**

### Community — MANQUANT

La navigation prévoit Communauté, mais aucun écran core n'existe encore.

La communauté doit rester orientée modding :
- support ;
- questions ;
- discussions ;
- studios/équipes ;
- activité ;
- signalements selon contexte.

**Décision : ajouter un wireframe Community desktop.**

### Security / Trust — PAS UN ÉCRAN CORE, MAIS SURFACE À PRÉVOIR

La confiance doit surtout apparaître dans les fiches, releases et actions d'installation.

Une page dédiée peut exister pour documentation/explication, mais elle ne doit pas devenir le seul endroit où les statuts importants sont visibles.

**Décision : pas de nouveau wireframe core immédiat ; intégrer les éléments de confiance dans les écrans principaux.**

### Documentation — NON PRIORITAIRE POUR LE FLOW CORE

La documentation reste nécessaire, mais peut être conçue après les parcours produit principaux.
