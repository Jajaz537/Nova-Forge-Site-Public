## Skyrim Special Edition

- règles de portage ;
- règles de monétisation/crowdfunding ;

**Résultat MODARYX : revue scope/licence explicite requise.**

- l'absence de réponse ne vaut pas accord.

**Résultat MODARYX : la politique publique ne prouve pas encore le scope précis d'hébergement/distribution de la plateforme.**

## Minecraft

Sources officielles :
- Minecraft Usage Guidelines ;
- Partnership Proposal.

Le préflight retient notamment :
- les guidelines visent la communauté/joueurs/fans ;
- les usages d'entreprises commerciales ne reçoivent pas une autorisation générale ;
- la redistribution du jeu ou de modifications de fichiers du jeu est limitée ;
- un chemin formel de proposition de partenariat existe ;
- ce qui n'est pas couvert ne doit pas être présumé permis.

**Résultat MODARYX : scope commercial/plateforme à valider explicitement.**
