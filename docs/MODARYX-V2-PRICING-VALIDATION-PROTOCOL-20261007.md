# MODARYX V2 — PRICING & VALUE VALIDATION PROTOCOL — 2026-10-07

**Statut : PLAN DE RECHERCHE — aucune vente, aucun prix canonique**

## 1. Questions à trancher

1. Le cœur gratuit apporte-t-il assez de valeur pour déclencher adoption et confiance ?
2. Existe-t-il une valeur récurrente suffisamment forte pour un Premium ?
3. Quelles capacités sont réellement perçues comme Premium ?
4. Les créateurs ont-ils des besoins professionnels payables ?
5. L'abonnement est-il accepté ou un achat ponctuel serait-il préféré ?

## 2. Offre gratuite à tester

Baseline :
- découverte/recherche ;
- compatibilité/dépendances/conflits ;
- provenance/licence/sécurité ;
- collections/favoris ;
- publication créateur de base ;
- communauté/signalement ;
- téléchargement manuel lorsqu'autorisé.

Ne jamais montrer une version gratuite artificiellement bridée.

## 3. Valeur Premium à tester

Tester séparément :
- profils/loadouts avancés ;
- version locking + rollback ;
- automatisation d'installation autorisée ;
- résolution avancée de conflits ;
- synchronisation cloud si réellement prévue ;
- personnalisation/confort avancé.

Ne pas tester la sécurité de base ou l'accessibilité comme upsell.

## 4. Prix stimuli

Sans vente réelle :
- 4,99 €/mois
- 6,99 €/mois
- 8,99 €/mois

Ces valeurs servent uniquement à mesurer la sensibilité au prix.

## 5. Recherche qualitative

Cible candidate : 12–20 personnes réparties entre joueur découverte, joueur avancé et créateur.

Questions :
- dernière difficulté réelle rencontrée avec des mods ;
- solution actuelle ;
- valeur perçue des fonctions MODARYX ;
- fonctions indispensables gratuites ;
- fonctions justifiant paiement ;
- objections ;
- préférence abonnement/achat ponctuel ;
- confiance/privacy.

## 6. Recherche quantitative

Cible candidate : 150–300 réponses qualifiées avant décision.

Mesurer :
- segment ;
- fréquence modding ;
- outils actuels ;
- intention d'essai ;
- importance des fonctions ;
- intention de payer par prix ;
- rejet de l'abonnement ;
- préférence annuelle ;
- fonction causant la décision.

## 7. Discipline de preuve

Un sondage ne prouve pas une conversion réelle.

Niveaux :
1. préférence déclarée ;
2. intention de payer ;
3. clic vers une offre de recherche clairement non achetable ;
4. pilote gratuit avec usage réel ;
5. vente réelle seulement après gates commercial + legal.

Ne jamais collecter de carte ni créer de fausse commande pour tester.

## 8. Creator pricing

Ne pas mélanger Premium utilisateur et offre créateur.

Tester séparément :
- analytics avancées ;
- équipes ;
- automatisation/API ;
- support pro.

Aucune commission sans analyse économique et juridique spécifique.

## 9. Critères avant prix canonique

- valeur récurrente prouvée ;
- coûts mesurés ;
- données willingness-to-pay ;
- politique remboursement ;
- TVA/taxes ;
- paiement choisi ;
- pilote activation/rétention ;
- décision explicite du propriétaire produit.

**État prix : PREUVE MANQUANTE.**
