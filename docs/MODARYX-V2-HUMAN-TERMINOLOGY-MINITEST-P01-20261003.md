# MODARYX V2 — Mini-test humain terminologique — P01

**Date : 2026-10-03**  
**Statut : TERMINÉ pour P01 — validation humaine globale EN COURS**

## 1. Objectif

Tester cinq libellés critiques après analyse croisée P01 + Work + étude indépendante.

Ce document représente le même participant réel P01. Il ne constitue pas un second participant.

## 2. Réponses brutes

### Q1 — Profils de jeu vs Configurations de jeu

Choix :
**A — Profils de jeu**

Scénario :
retrouver une configuration GTA VI avec plusieurs mods et leurs versions précises.

Lecture :
- lorsqu'on lui présente explicitement les deux libellés, P01 préfère **Profils de jeu** ;
- cela nuance le premier mini-test : le problème observé précédemment était surtout la **trouvabilité** depuis Bibliothèque, pas nécessairement le mot “Profil” lui-même.

**État : PROFILS DE JEU PRÉFÉRÉ PAR P01**

### Q2 — Collection

Choix :
**A — une sélection de mods organisée à partager**

Lecture :
- P01 comprend spontanément Collection dans le sens éditorial souhaité par MODARYX ;
- le risque de confusion avec une Collection installable existe toujours pour d'autres publics familiers de Nexus/Steam, mais il n'est pas observé chez P01.

**État : COMPRIS PAR P01**

### Q3 — Bibliothèque

Choix :
**A — mes favoris, collections, modpacks et profils/configurations**

Lecture :
- P01 comprend Bibliothèque comme un espace personnel transversal ;
- la trouvabilité des sous-objets doit néanmoins rester explicite.

**État : COMPRIS PAR P01**

### Q4 — Mods & Plugins comme parapluie

Choix :
**B — pour moi cela veut seulement dire mods et plugins**

Lecture :
- le libellé **Mods & Plugins** échoue chez P01 comme parapluie naturel pour addons, scripts, outils, maps, shaders, presets, etc. ;
- une microcopy secondaire ne garantit pas que l'utilisateur comprendra la portée avant d'entrer dans la rubrique.

**État : AMBIGUÏTÉ RÉELLE / LIBELLÉ NON STABILISÉ**

### Q5 — Non vérifié

Réponse :
**A + B + C**

P01 comprend simultanément :
- peut-être dangereux ;
- pas encore testé/vérifié ;
- provenance inconnue.

Lecture :
- **Non vérifié** seul est trop ambigu ;
- le produit doit toujours qualifier la dimension.

Décision sûre :
- **Compatibilité non vérifiée** ;
- **Provenance inconnue** ou **provenance non vérifiée** selon preuve réelle ;
- **Non analysé** pour un scan absent ;
- un risque réel doit être nommé comme tel, jamais inféré du seul état “Non vérifié”.

**État : LIBELLÉ GÉNÉRIQUE À ÉCARTER**

## 3. Conséquences de conception

1. Restaurer **Profils de jeu** comme libellé utilisateur provisoire préféré, avec microcopy descriptive.
2. Conserver l'accès contextualisé depuis le Game Hub pour résoudre le problème de trouvabilité.
3. Conserver **Collection**, avec capacité d'installation toujours explicite.
4. Conserver **Bibliothèque**, avec sous-objets visibles.
5. Ne pas considérer **Mods & Plugins** comme libellé parapluie final tant qu'une alternative n'a pas été testée.
6. Interdire le badge générique **Non vérifié** sans dimension.

## 4. Limite de preuve

P01 reste un seul participant réel.

La validation humaine globale reste **EN COURS**.

Le prochain test utile n'est pas de refaire les mêmes questions, mais de comparer quelques alternatives au libellé parapluie de contenus.
