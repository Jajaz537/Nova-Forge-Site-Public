# MODARYX V2 — matrice de readiness internationale — 2026-10-08

**État : EN COURS — aucun marché n'est déclaré prêt juridiquement par ce document**

## Règle

**Accessible sur Internet ≠ prêt au lancement dans un territoire.**

Un territoire n'est ajouté au lancement qu'après décision explicite et revue adaptée :
- produit/vente autorisés ;
- consommateur ;
- privacy ;
- cookies/marketing ;
- paiements/refunds ;
- taxes/facturation ;
- licences/droits ;
- accessibilité ;
- sécurité ;
- support/litiges ;
- obligations plateforme/UGC applicables.

## Politique de lancement

Tant que le propriétaire produit n'a pas choisi les territoires :
- aucun marketing ciblé hors marchés approuvés ;
- aucune vente payante hors marchés approuvés ;
- aucun prix local présenté comme canonique ;
- aucune affirmation de conformité globale.

La décision éventuelle de géoblocage ou limitation territoriale reste **PREUVE MANQUANTE** et doit être proportionnée, techniquement réalisable et juridiquement revue.
