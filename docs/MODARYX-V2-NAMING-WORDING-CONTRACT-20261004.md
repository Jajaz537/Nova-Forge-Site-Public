# MODARYX V2 — Contrat canonique de nommage et wording

**Date : 2026-10-04**  
**Statut : ACTIF — décision produit / identité**

## 1. Séparation de marque

- **MODARYX / MODARYX MODS** = plateforme web.
- **MODARYX Forge** = logiciel / écosystème desktop.
- **MODARYX Public** = édition publique desktop.
- **MODARYX Founder** = édition Founder desktop.
- `Nova Forge OS` = nom produit retiré ; uniquement legacy/provenance/compatibilité technique lorsque nécessaire.
- `getnovaforge.com` / getnova = ancien projet web abandonné ; jamais cible actuelle.

Interdictions :
- ne pas appeler les éditions « MODARYX Forge Public » ou « MODARYX Forge Founder » ;
- ne pas réintroduire `Nova Forge OS` comme nom produit actif ;
- ne pas lancer de migration de marque MODARYX → Nova Forge ;
- ne pas remplacer aveuglément les identifiants legacy techniques.

## 2. Wording contenu

Libellé parapluie principal :
**Mods & contenus**

Microcopy :
**Mods, plugins, addons, scripts, maps, shaders, presets, outils et autres contenus pour vos jeux.**

Règles :
- `Mods & Plugins` ne doit pas redevenir le parapluie universel ;
- les types précis restent visibles selon le jeu.

## 3. Wording profils

Libellé :
**Profils de jeu**

Microcopy :
**Configurations enregistrées de mods, versions et réglages.**

Game Hub :
**Mes profils pour ce jeu**

Action :
**Ajouter à un profil de jeu**

État vide :
**Aucun profil de jeu**

Le domaine interne peut conserver `Profile`, `Loadout`, `profile-loadout`.

Le compte utilisateur reste :
- **Compte**
- **Profil public**

selon le contexte.

## 4. Trust wording

Le badge générique **Non vérifié** est interdit seul.

Toujours qualifier la dimension :
- Compatibilité non vérifiée / non testée ;
- Provenance inconnue ;
- Fichier non analysé ;
- En attente de modération ;
- Conflit non évalué.

## 5. Game Atmosphere

Le produit reste MODARYX.

Formulation de référence :
- **Ambiance originale MODARYX**
- **On change de monde, pas de produit.**

Aucune ambiance de jeu réel ne doit introduire une marque/asset éditeur non autorisé ou faire croire à une affiliation.

## 6. IA

Nom produit :
**MODARYX IA**

MODARYX IA appartient au produit MODARYX mais ne doit jamais être présentée comme active si aucun provider/runtime réel n'est connecté.

## 7. Statut

Ces décisions sont actives pour toute nouvelle surface V2.

La validation humaine globale reste distincte et PREUVE MANQUANTE là où le checkpoint la requiert.
