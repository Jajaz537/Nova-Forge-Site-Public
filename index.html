Règle publique : une information absente reste absente. Le site ne transforme jamais « inconnu » en « vérifié » pour améliorer sa présentation. Ouvrir le contrat Sécurité & provenance. Vérifier un fichier localement. Consulter le statut public JSON.

Vie privée

Le noyau public fonctionne sans profil distant.

Local-first

Dans cette version du site, les fonctions interactives disponibles sont exécutées dans le navigateur. Aucun compte ni backend distant n’est nécessaire pour consulter le contenu public ou utiliser la démonstration locale.

Smart Profile local

L’analyse utilise uniquement les informations que le navigateur expose à la page, puis affiche le résultat localement. Elle n’envoie pas ce résultat à un service Nova Forge distant.

Traitement navigateur

Préférences locales

Le noyau peut mémoriser localement une préférence liée à la réduction des animations. Cette donnée reste dans le stockage du navigateur et n’est pas requise pour consulter le site.

Le service worker met en cache les ressources statiques du même site pour améliorer la disponibilité hors ligne. Aucun domaine tiers n’est requis par ce noyau.
